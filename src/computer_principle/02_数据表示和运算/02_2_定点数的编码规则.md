## 2.2.1 定点数的编码规则

### 1. 定点数的编码规则

- 真值、机器数、数符、数值
- 原码表示法（符号-数值表示法）
- 补码表示法（2-补码表示法）
- 反码表示法
- 移码表示法

## 2.2.2 原码

### 1. 概念

原码采用**符号-数值表示法**：最高位表示数的符号，其余各位表示该数绝对值的二进制数值。

<span style="color:#c0392b; text-decoration:underline">**符号位为 0 表示正，符号位为 1 表示负；正、负数绝对值相同时，原码只有符号位不同。**</span>

以 8 位原码表示整数为例，1 位为符号位，7 位为数值位：

| 真值 | 原码 | 说明 |
|------|------|------|
| +5 | `0000 0101` | 符号位为 0，数值位表示 5 |
| -5 | `1000 0101` | 符号位为 1，数值位表示 5 |
| +0 | `0000 0000` | 符号位为 0，数值位全为 0 |
| -0 | `1000 0000` | 符号位为 1，数值位全为 0 |

### 2. 表示范围

设原码总位数为 $n$（包含 1 位符号位），则数值位有 $n-1$ 位，$X$ 表示真值。

#### （1）定点整数

<span style="color:#c0392b; text-decoration:underline">**n 位原码定点整数的表示范围：**</span>

$$
-\left(2^{n-1}-1\right) \le X \le 2^{n-1}-1
$$

| 总位数（含符号位） | 表示范围 |
|------|------|
| 8 位 | -127 ～ 127 |
| 16 位 | -32767 ～ 32767 |

#### （2）定点小数

小数点隐含在符号位之后，$n-1$ 位数值位全部表示小数部分，最大绝对值为：

$$
0.\underbrace{11\cdots1}_{n-1\text{ 位}} = 1-2^{-(n-1)}
$$

<span style="color:#c0392b; text-decoration:underline">**n 位原码定点小数的表示范围：**</span>

$$
-\left(1-2^{-(n-1)}\right) \le X \le 1-2^{-(n-1)}
$$

例如，8 位原码定点小数的范围为 $-127/128$ ～ $127/128$，即 $-0.9921875$ ～ $0.9921875$。

### 3. 原码的优点和缺点

**优点：**

- **直观易懂**：符号和数值分开表示，与日常书写正、负数的习惯一致。
- **与真值转换方便**：保留绝对值的二进制表示，只需根据正负设置符号位。
- **便于实现乘除法的符号处理**：结果符号可由两个操作数的符号位异或得到，数值部分按绝对值处理。

**缺点：**

- <span style="color:#c0392b; text-decoration:underline">**0 有 +0 和 -0 两种编码，判断零时需要同时识别两种情况。**</span>因此，n 位原码共有 $2^n$ 种编码，但只能表示 $2^n-1$ 个不同的数值。
- <span style="color:#c0392b; text-decoration:underline">**加减运算时，不能将符号位和数值位作为一个整体直接进行普通二进制加法。**</span>需要先判断操作类型和符号，必要时比较绝对值，再决定数值部分做加法还是减法以及结果的符号，控制较复杂。

例如，用 8 位原码直接做普通二进制加法：`0000 0101`（+5）加 `1000 0101`（-5）得到 `1000 1010`，按原码解释为 -10，而正确结果应为 0。

## 2.2.3 补码

### 1. 概念

补码（two’s complement，二进制补码）是计算机中表示有符号整数最常用的编码方式。

### 2. 为什么用补码

- **加减法统一**：减法可以变成加法，CPU 只需要一套加法器。
- **0 只有一种表示**：原码和反码里有 +0 和 -0 两个零，补码里只有 `0000 0000`（以 8 位为例）。
- **符号位直接参与运算**，不需要特殊处理。

### 3. 表示范围

设补码总位数为 $n$（包含 1 位符号位），$X$ 表示真值。

#### （1）定点整数

<span style="color:#c0392b; text-decoration:underline">**n 位补码定点整数的表示范围：**</span>

$$
-2^{n-1} \le X \le 2^{n-1}-1
$$

| 总位数（含符号位） | 表示范围 |
|------|------|
| 8 位 | -128 ～ 127 |
| 16 位 | -32768 ～ 32767 |

范围不对称是因为 0 占用了一个非负数的位置，所以负数比正数多一个。以 8 位补码为例，最小值 `1000 0000` 表示 -128。

#### （2）定点小数

小数点隐含在符号位之后，$n-1$ 位数值位全部表示小数部分。

<span style="color:#c0392b; text-decoration:underline">**n 位补码定点小数的表示范围：**</span>

$$
-1 \le X \le 1-2^{-(n-1)}
$$

例如，8 位补码定点小数的范围为 $-1$ ～ $127/128$，即 $-1$ ～ $0.9921875$。

### 4. 计算方法

- 正数的补码 = 原码。
- 负数的补码：原码符号位不变，数值位按位取反，末位加 1。

上述负数转换方法适用于同位数原码能够表示的负数。最小负数 $-2^{n-1}$ 没有同位数的原码表示，其 n 位补码为 `100…0`。

### 5. 补码表示法

- 正数的补码是自身：$[X_T]_{\text{补}} = X_T = M + X_T \pmod M$
- 负数的补码是模与该数绝对值的差：$[X_T]_{\text{补}} = M - |X_T| = M + X_T \pmod M$
- 0 的补码：$[+0]_{\text{补}} = [-0]_{\text{补}} = 2^n \pm 0 = 10\cdots0 = 00\cdots0 \pmod {2^n}$
- -1 的补码：$[-1]_{\text{补}} = 2^n - 1 = 11\cdots1$（$n$ 个 1）

## 2.2.4 几种计算题型

- 已知真值求原码、已知原码求真值（进制转换）
- 已知原码（或真值）求补码（注意补码位数）
- 已知补码求原码（或真值）
- 已知补码求原码相反数的补码

## 2.2.5 例题

1. 当补码位数分别为 $n$ 位、$n+1$ 位时，求 $-2^{n-1}$ 的补码

2. 设补码位数为 8，求 $110\ 1100$ 和 $-110\ 1100$ 的补码

3. `int x = -1, unsigned int u = 2147483648`

   把 x 转成无符号数是多少，把 u 转成有符号数是多少？

4. 已知 $[X_T]_{\text{补}} = 1011\ 0100$，求 $[-X_T]_{\text{补}}$

5. 已知 $[X_T]_{\text{补}} = 1011\ 0100$，求真值 $X_T$
