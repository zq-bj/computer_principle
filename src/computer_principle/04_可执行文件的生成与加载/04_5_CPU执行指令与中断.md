## 4.5.1 指令执行过程与 CPU 组成

### 1. 指令周期

CPU 取出并执行一条指令的时间称为指令周期。课件列出以下过程：

1. 取指令：由 PC 给出指令地址。
2. 译码：对 IR 中指令的操作码进行译码。
3. 计算源操作数地址并取操作数。
4. 执行数据操作。
5. 计算目的操作数地址并保存结果。
6. 计算后续指令地址并送入 PC。

### 2. 指令功能的基本操作

- 读存储单元内容。
- 把寄存器数据送到指定存储单元。
- 在寄存器之间传送数据。
- 在 ALU 中完成算术、逻辑运算，把结果送入寄存器。

### 3. CPU 的基本组成

| 部件 | 作用或关注点 |
|------|--------------|
| PC | 保存指令地址 |
| IR | 保存当前指令 |
| ID | 指令译码 |
| ALU、寄存器 | 运算与暂存数据 |
| 启停控制逻辑 | 控制运行、停止 |
| 时序信号产生部件 | 产生时序信号 |
| 操作控制信号形成部件 | 形成操作控制信号 |
| 总线控制逻辑 | 协调总线操作 |
| 中断机构 | 处理异常、中断 |

## 4.5.2 异常与中断

**中断事件：**

- 非法操作码
- 页故障
- 运算结果溢出
- 收到中断请求信号

执行被打断时的处理逻辑，称为<span style="color:#c0392b; text-decoration:underline">**中断机制（或异常控制）**</span>。

CPU 中异常和中断处理逻辑称为<span style="color:#c0392b; text-decoration:underline">**中断机构**</span>。

## 4.5.3 指令流水线

<span style="color:#c0392b; text-decoration:underline">**考试重点：指令流水线。**</span>

### 1. 四段流水线

| 阶段 | 名称 | 课件中的操作 |
|------|------|--------------|
| IF | 取指 | 取指令<span style="color:#c0392b">并</span>更新 PC |
| ID | 译码 | 译码<span style="color:#c0392b">并</span>读寄存器 |
| EX | 执行 | 运算<span style="color:#c0392b">或</span>读存储器 |
| WB | 写回 | 结果写回 |

```mermaid
flowchart LR
    A[IF 取指] --> B[ID 译码与读寄存器]
    B --> C[EX 运算或访存]
    C --> D[WB 结果写回]
```

<span style="color:#c0392b; text-decoration:underline">**流水线让多条指令在不同阶段重叠执行，提高指令处理的吞吐率。**</span>
