## 4.2.1 符号与符号表

### 1. 符号分类

| 类别 | 含义 | 典型对象 |
|------|------|----------|
| 全局符号 | 本模块定义，其他模块也可引用 | 非 static 函数、全局变量 |
| 外部符号 | 其他模块定义，本模块引用 | 外部函数、外部变量 |
| 本地符号 | 仅在本模块内使用 | static 函数、static 变量 |

<span style="color:#c0392b; text-decoration:underline">**链接器的本地符号与函数中的自动局部变量不同。普通自动局部变量不作为链接符号记录在 `.symtab` 中。**</span>

静态局部变量具有静态存储期，可以对应本地符号，并在 `.data` 或 `.bss` 中分配空间。

### 2. ELF 符号表表项

| 字段 | 含义 |
|------|------|
| `st_name` | 符号名在字符串表中的字节偏移 |
| `st_value` | 可重定位文件中通常为节内偏移；可执行或共享目标文件中按相应格式表示符号地址 |
| `st_size` | 对象的字节数 |
| <span style="color:#c0392b; text-decoration:underline">**st_info**</span> | 共 8 位：低 4 位表示符号类型，高 4 位表示绑定属性 |
| `st_other` | 符号可见性 |
| <span style="color:#c0392b; text-decoration:underline">**st_shndx**</span> | 符号所在节的节头表索引，或 ABS、UNDEF、COMMON 等特殊值 |

#### （1）st_info：符号类型与绑定属性

<span style="color:#c0392b; text-decoration:underline">**st_info 的低 4 位记录“是什么”，高 4 位记录“如何绑定”。**</span>

**低 4 位：符号类型。**

| 类型 | 含义 |
|------|------|
| NOTYPE | 未指定类型 |
| OBJECT | 数据对象，如变量、数组 |
| FUNC | 函数 |
| SECTION | 节符号，主要用于重定位 |

**高 4 位：绑定属性。**

| 绑定属性 | 含义 |
|------|------|
| LOCAL | 本地符号，仅在当前目标文件内可见 |
| GLOBAL | 全局符号，可用于解析其他模块的符号引用 |
| WEAK | 弱符号，定义的优先级低于同名的全局定义 |

符号类型和绑定属性是两个独立维度，例如函数可以是 FUNC + GLOBAL，也可以是 FUNC + LOCAL。`st_other` 另行记录符号的可见性。

#### （2）st_shndx：所在节的索引与特殊值

<span style="color:#c0392b; text-decoration:underline">**st_shndx 通常是符号所在节的节头表索引；ABS、UNDEF、COMMON 是具有特殊含义的值，不是普通节名。**</span>

| 特殊值 | 完整名称 | 含义 |
|------|------|------|
| ABS | `SHN_ABS` | 绝对符号，符号值不随重定位改变 |
| UNDEF | `SHN_UNDEF` | 本目标文件中未定义，通常需要链接时从其他模块寻找定义 |
| COMMON | `SHN_COMMON` | 公共符号，尚未分配到具体节，链接时再分配空间；课件中用于按 COMMON 方式处理的未初始化全局变量 |

未初始化全局变量不一定是 COMMON，也可能直接分配到 `.bss`，应结合编译选项和符号表判断。

## 4.2.2 符号解析

### 1. 基本概念

<span style="color:#c0392b; text-decoration:underline">**符号解析把模块中的符号引用与定义该符号的模块建立关联。**</span>

### 2. 强符号、COMMON 符号与弱符号

课件中，全局符号包括以下三类：

- <span style="color:#c0392b; text-decoration:underline">**强符号**</span>：未显式声明为弱符号时，包括：<br/>
  函数。<br/>
  `.data` 节中有初值的全局变量。<br/>
  `.bss` 节中初始化为 0 的全局变量。
- <span style="color:#c0392b; text-decoration:underline">**COMMON 符号**</span>：COMMON 伪节中的未初始化全局变量，按课件采用的 COMMON 方式处理。
- <span style="color:#c0392b; text-decoration:underline">**弱符号**</span>：绑定属性为 WEAK 的符号。

### 3. 同名全局符号的处理规则

1. 强符号不能多次定义，否则链接报错。
2. 一个强符号与多个 COMMON 或弱符号同名时，以强符号为准。
3. COMMON 与弱符号同名时，课件规则以 COMMON 为准。
4. 同一个 COMMON 符号出现多次时，按占用空间最大的定义分配。
5. 使用 `-fno-common` 时，相关未初始化全局变量不再按 COMMON 合并，重复定义可能报错。

以上 COMMON 题目按课件指定模型分析，不把它当成所有编译环境的默认行为。

**总结：**

<span style="color:#c0392b; text-decoration:underline">**两强符号会报错。**</span><br/>
<span style="color:#c0392b; text-decoration:underline">**强符号 > COMMON 符号 > 弱符号。**</span><br/>
<span style="color:#c0392b; text-decoration:underline">**两 COMMON 符号，谁空间大谁厉害（按较大的空间分配）。**</span>

### 4. 课件同名符号示例

#### （1）两个强符号同名

```c
/* main.c */
int x = 10;
int y;
int p1(void);
int main() {
    x = p1();
    return x;
}
```

```c
/* p1.c */
int x = 20;
int y = 0;
int p1() {
    return x;
}
```

分析重点：两个模块中的 `x` 都有初值，应依据强符号规则判断链接情况。

#### （2）同名变量的类型不一致

```c
/* main.c */
#include <stdio.h>
int y = 100, z;
void p1(void);
int main() {
    z = 1000;
    p1();
    printf("y=%d,z=%d\n", y, z);
    return 0;
}
```

```c
/* p1.c */
int y;
short z;
void p1() {
    y = 200;
    z = 2000;
}
```

分析重点：同名符号的关联、存储空间及类型不一致带来的问题。

### 5. 避免同名全局符号问题

- 减少使用全局变量；只在当前模块使用时采用 `static`。
- 给全局变量赋初值，使定义更明确。
- 引用其他模块的全局变量时使用 `extern` 声明，并保持类型一致。
