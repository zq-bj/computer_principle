## 4.6.2 符号表分析题

### 1. 题目（第 30 页，原题 4）

程序有 main.c 和 swap.c 两个源文件。

```c
/* main.c */
extern void swap();
int buf[2] = {1, 2};
int main() {
    swap();
    return 0;
}
```

```c
/* swap.c */
extern int buf[];
int *bufp0 = &buf[0];
int *bufp1;

static void incr() {
    static int count = 0;
    count++;
}

void swap() {
    int temp;
    incr();
    bufp1 = &buf[1];
    temp = *bufp0;
    *bufp0 = *bufp1;
    *bufp1 = temp;
}
```

对编译生成的 swap.o，说明各符号是否出现在 `.symtab` 中；若出现，填写定义模块、相对于 swap.o 的符号类型（全局、外部、本地），以及所在节或特殊伪节。

## 4.6.3 符号引用与定义关联题

### 1. 题目（第 31 页，原题 6 的第 1 小题）

两个源文件分别编译为 m1.o、m2.o。用 `REF(mj.x) → DEF(mi.x)` 表示模块 mj 中符号 x 的引用关联到模块 mi 中符号 x 的定义。

```c
/* m1.c */
int p1(void);
int main() {
    int p1 = p1();
    return p1;
}
```

```c
/* m2.c */
static int main = 1;
int p1() {
    main++;
    return main;
}
```

以上按课件保留原代码，包括 m1.c 中局部变量与函数同名的写法；分析时应先判断该写法是否能通过编译。

### 2. 待填写关联

- `REF(m1.main) → DEF(____.____)`
- `REF(m2.main) → DEF(____.____)`
- `REF(m1.p1) → DEF(____.____)`
- `REF(m2.p1) → DEF(____.____)`

若发生错误，说明原因；若可对应多个定义，给出全部可能定义；若是局部变量，说明不存在链接关联。本页保留题目，不填答案。
