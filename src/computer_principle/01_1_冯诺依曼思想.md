## 冯·诺依曼结构的主要思想

1. 计算机应由<span style="color:#c0392b; text-decoration:underline">**运算器**</span>、<span style="color:#c0392b; text-decoration:underline">**控制器**</span>、<span style="color:#c0392b; text-decoration:underline">**存储器**</span>、<span style="color:#c0392b; text-decoration:underline">**输入设备**</span>和<span style="color:#c0392b; text-decoration:underline">**输出设备**</span>五个基本部件组成。

2. 各基本部件的功能是：

   - <span style="color:#c0392b; text-decoration:underline">**存储器**</span>不仅能存放数据，而且也能存放指令，形式上两者没有区别，但计算机应能区分数据还是指令；

   - <span style="color:#c0392b; text-decoration:underline">**控制器**</span>应能自动取出指令来执行；

   - <span style="color:#c0392b; text-decoration:underline">**运算器**</span>应能进行加/减/乘/除四种基本算术运算，并且也能进行一些逻辑运算和附加运算；

   - 操作人员可以通过<span style="color:#c0392b; text-decoration:underline">**输入设备**</span>、<span style="color:#c0392b; text-decoration:underline">**输出设备**</span>和主机进行通信。

3. 内部以<span style="color:#c0392b; text-decoration:underline">**二进制**</span>表示指令和数据。每条指令由操作码和地址码两部分组成。操作码指出操作类型，地址码指出操作数的地址。由一串指令组成程序。

4. 采用“<span style="color:#c0392b; text-decoration:underline">**存储程序**</span>”工作方式。

## 名词解释

| 缩写 | 英文全称 | 中文名称 | 功能说明 |
|------|----------|----------|----------|
| <span style="color:#c0392b; text-decoration:underline">**CPU**</span> | Central Processing Unit | 中央处理器 | 计算机的核心部件，包含控制器和运算器 |
| <span style="color:#c0392b; text-decoration:underline">**PC**</span> | Program Counter | 程序计数器 | 存放下一条要执行指令的地址 |
| <span style="color:#c0392b; text-decoration:underline">**MAR**</span> | Memory Address Register | 存储器地址寄存器 | 存放要访问的存储单元地址 |
| <span style="color:#c0392b; text-decoration:underline">**MDR**</span> | Memory Data Register | 存储器数据寄存器 | 存放从存储器读出或写入的数据 |
| <span style="color:#c0392b; text-decoration:underline">**IR**</span> | Instruction Register | 指令寄存器 | 存放当前正在执行的指令 |
| <span style="color:#c0392b; text-decoration:underline">**ALU**</span> | Arithmetic Logic Unit | 算术逻辑部件 | 执行算术运算和逻辑运算 |
| <span style="color:#c0392b; text-decoration:underline">**GPRs**</span> | General Purpose Registers | 通用寄存器组 | 存放操作数和中间结果 |

## 指令执行过程

一条指令的执行过程分为以下步骤：

1. **取指**：PC的值送到MAR，从存储器中取出指令送到MDR，再送到IR
2. **译码**：控制器对IR中的指令进行译码，确定操作类型
3. **执行**：根据译码结果，控制器发出控制信号，ALU执行相应运算
4. **回写**：将运算结果写回寄存器或存储器

```mermaid

    PC->>MAR: PC值送到MAR

    MDR->>IR: 指令送到IR
    
    Note over PC,ALU: 2. 译码阶段
    IR->>Controller: 指令译码
    
    Note over PC,ALU: 3. 执行阶段
    Controller->>ALU: 发送控制信号
    ALU->>ALU: 执行运算
    
    Note over PC,ALU: 4. 回写阶段
    ALU->>MDR: 结果送到MDR
    MDR->>Mem: 写回存储器
```
