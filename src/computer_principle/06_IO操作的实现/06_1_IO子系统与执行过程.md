## 6.1.1 I/O 子系统概述

![图 6.1 I/O 子系统层次结构](/images/chapter06/io-subsystem-hierarchy.png)

### 1. 基本任务

I/O 子系统解决计算机的信息输入与输出问题，由 I/O 软件与 I/O 硬件共同完成。

### 2. 软件层次

- 用户空间 I/O 软件：用户程序中的请求、运行时系统。
- 内核空间 I/O 软件：与设备无关的软件、设备驱动程序、中断服务程序。

### 3. I/O 硬件的三个特性

| 特性 | 理解 |
|------|------|
| 共享性 | 多个进程共享设备 |
| 复杂性 | 实现细节复杂，由软件层次屏蔽差异 |
| 异步性 | 外设通常较慢，可能通过异步中断报告事件 |
