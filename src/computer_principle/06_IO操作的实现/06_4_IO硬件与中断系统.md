## 6.4.1 I/O 设备

### 1. 字符设备

以字符为单位向主机发送或从主机接收字符流。

- 输入设备：把数据、命令、字符、图形图像、声音等转换为二进制编码输入计算机。
- 输出设备：把计算结果转换为人能理解的文字、图形图像、声音等，输出到显示器、打印机等。

### 2. 块设备

以固定大小的数据块为单位，与主机交换信息。

## 6.4.2 总线互连

### 1. 课件中的总线类型

- 处理器总线：前端总线 FSB、QPI 总线。
- 存储器总线。
- I/O 总线：课件以 PCI-e 1.0 为例。

### 2. 带宽计算

存储器总线带宽：

$$
\text{带宽}=\text{每秒传输次数}\times\text{总线宽度}\times\text{通道数}
$$

总线宽度用 bit 计时，结果为 bit/s；换算为 B/s 需要除以 8。

课件 PCI-e 1.0 示例按每通道每方向 2.5 GT/s、8b/10b 编码计算。双向合计带宽为：

$$
\text{双向带宽}=2.5\times 10^9\times\frac{8}{10}\times\frac{1}{8}\times 2\times\text{通道数}\quad\text{B/s}
$$

即课件中的 `2.5 × 2 × 通道数 / 10` GB/s；其中乘 2 表示两个方向合计，单向带宽不乘 2。

## 6.4.3 I/O 接口与端口编址

### 1. I/O 接口功能

1. **数据缓冲**：在接口中暂存待传送的数据，协调 CPU、主存与外设之间的速度差异。例如，外设送来的数据先存入接口的数据缓冲寄存器，等待 CPU 读取。
2. **错误和就绪检测**：检测设备是否已准备好进行数据传送，以及传送过程中是否发生错误，并通过状态信息供 CPU 查询。例如，输入数据是否已到达、输出设备是否空闲、传送的数据是否出现校验错误。
3. **控制与定时**：接收并解释 CPU 发来的控制命令，向外设发送相应的控制信号，并协调各步骤的先后顺序和时间配合。例如，按“启动设备 → 等待就绪 → 传送数据 → 确认完成”的顺序控制一次传送。
4. **数据格式转换**：将主机与外设使用的不同数据形式相互转换，使双方能够交换数据。例如，主机内部采用并行传送，而外设采用串行传送时，接口需要完成并行与串行之间的转换。

### 2. I/O 端口

- 数据端口：传送数据。
- 状态端口：读取设备状态。
- 控制端口：发送控制信息。

### 3. 编址方式

| 方式 | 特点 |
|------|------|
| 独立编址 | I/O 端口与主存使用独立的地址空间 |
| 统一编址（存储器映射） | I/O 端口纳入存储器地址空间 |

## 6.4.4 中断系统

### 1. 主要功能

- 记录中断请求。
- 响应中断请求。
- 按优先级选择中断请求。
- 保护被打断程序的断点和现场。

### 2. 中断优先级

| 概念 | 作用 |
|------|------|
| 响应优先级 | 由中断判优电路等决定先响应哪个请求 |
| 处理优先级 | 通过中断屏蔽等机制，安排处理过程中的优先关系 |

<span style="color:#c0392b; text-decoration:underline">**响应优先级关注“先响应谁”，处理优先级关注“处理期间谁能打断谁”。**</span>
