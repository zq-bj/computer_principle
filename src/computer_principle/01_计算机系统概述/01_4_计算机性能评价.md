## 1.4.1 计算机系统性能评价

1. 吞吐率
2. 响应时间
3. 执行时间
4. 流畅度、清晰度、实时性

$$
\text{计算机的性能} = \frac{1}{\text{时间（用户 CPU 时间）}}
$$

即<span style="color:#c0392b; text-decoration:underline">**用户 CPU 时间越高，性能越低**</span>。

## 1.4.2 执行时间

- **CPU 时间**
  - 用户 CPU 时间
  - 系统 CPU 时间
- **其他时间**（I/O 等待时间）

用户 CPU 时间与系统 CPU 时间的区别：

| 对比项 | 用户 CPU 时间 | 系统 CPU 时间 |
|--------|--------------|--------------|
| 运行状态 | 用户态（目态） | 内核态（管态） |
| 执行的代码 | 用户程序自身的指令 | 操作系统内核代码 |
| 典型活动 | 计算、循环、逻辑处理 | 系统调用、中断处理、进程调度、内存分配、设备驱动 |

<span style="color:#c0392b; text-decoration:underline">**进程 CPU 时间 = 用户 CPU 时间 + 系统 CPU 时间**</span>。

例如调用 `read()` 读文件时，用户程序中的循环和数据处理计入用户 CPU 时间；进入内核寻找磁盘、处理中断、复制数据的部分计入系统 CPU 时间。

## 1.4.3 CPU 时间的几个概念

- 时钟周期：是 CPU 工作的最小时间单位，即一个节拍的时间长度。

  ![时钟周期及时间单位换算](/images/chapter01/clock-cycle-units.png)

- 时钟频率：即主频，表示 CPU 每秒完成的时钟周期数，单位为 Hz（赫兹）。主频越高，单位时间内能处理的时钟周期越多。

  ![时钟频率及频率单位换算](/images/chapter01/clock-frequency-units.png)

- <span style="color:#c0392b; text-decoration:underline">**时钟周期和时钟频率互为倒数关系**</span>。
- CPI（Cycles Per Instruction）：执行一条指令平均所需的时钟周期数。

## 1.4.4 计算公式

### 1. 基础关系

$$
\text{时钟周期} = \frac{1}{\text{时钟频率}}
\qquad
\text{时钟频率} = \frac{1}{\text{时钟周期}}
$$

### 2. 用户 CPU 时间的所有写法

$$
\begin{aligned}
\text{用户 CPU 时间} &= \frac{\text{总时钟周期数}}{\text{时钟频率}} \\[4pt]
&= \text{总时钟周期数} \times \text{时钟周期} \\[4pt]
&= \frac{\text{指令条数} \times \text{综合 CPI}}{\text{时钟频率}} \\[4pt]
&= \text{指令条数} \times \text{综合 CPI} \times \text{时钟周期}
\end{aligned}
$$

### 3. 总时钟周期数

$$
\text{总时钟周期数} = \text{指令条数} \times \text{综合 CPI}
$$

### 4. 综合 CPI

$$
\begin{aligned}
\text{综合 CPI} &= \text{指令1占比} \times \text{CPI}_1 \\
&+ \text{指令2占比} \times \text{CPI}_2 \\
&+ \text{指令3占比} \times \text{CPI}_3 \\
&+ \cdots
\end{aligned}
$$

### 5. 关系图

$$
\text{指令条数} \times \text{综合 CPI}
= \text{总时钟周期数}
\xrightarrow{\ \div\ \text{时钟频率}\ \text{（或}\ \times\ \text{时钟周期）}\ }
\text{用户 CPU 时间}
$$

本质上就一个公式，只是根据已知条件换不同写法而已。
