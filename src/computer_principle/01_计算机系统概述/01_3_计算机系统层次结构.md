## 1.3.1 计算机系统的层次结构

从上到下依次为：

1. 应用
2. 算法
3. 编程
4. 操作系统/虚拟机
5. 指令集体系结构
6. 微体系结构
7. 功能部件
8. 电路
9. 器件

## 1.3.2 计算机系统结构的层次划分

从上到下依次为：

1. 应用语言机器级
2. 高级语言机器级
3. 汇编语言机器级
4. 操作系统
5. 机器语言机器级
6. 微程序机器级

## 1.3.3 API 与 ABI

- **API**：应用程序编程接口
- **ABI**：应用程序二进制接口
