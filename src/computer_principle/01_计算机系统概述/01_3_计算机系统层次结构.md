## 1.3.1 计算机系统的层次结构

### 1. 软硬件的分界

指令集体系结构（ISA）又称为<span style="color:#c0392b; text-decoration:underline">**指令系统**</span>。

计算机系统以<span style="color:#c0392b; text-decoration:underline">**指令集体系结构（ISA）为软硬件的分界**</span>：其上是软件层次，其下是硬件层次。

## 1.3.2 计算机系统结构的层次划分

从上到下依次为：

1. 应用语言机器级
2. 高级语言机器级
3. 汇编语言机器级
4. 操作系统
5. 机器语言机器级
6. 微程序机器级

## 1.3.3 API 与 ABI

- **API**：应用程序编程接口
- **ABI**：应用程序二进制接口
