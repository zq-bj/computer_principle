#### 2）注释 product 的汇编指令并判断数据类型（原题 10）

假设函数 product 的 C语言代码如下，其中 num_type 是用 typedef 声明的数据类型。

```c
void product(num_type *d, unsigned x, num_type y) {
    *d = x * y;
}
```

函数 product 的过程体对应的主要汇编代码如下：

```asm
movl  12(%ebp), %eax
movl  20(%ebp), %ecx
imull %eax, %ecx
mull  16(%ebp)
leal  (%ecx, %edx), %edx
movl  8(%ebp), %ecx
movl  %eax, (%ecx)
movl  %edx, 4(%ecx)
```

请给出上述每条汇编指令的注释，并说明 num_type 是什么类型。

#### 3）分析 lproc 并补全 C代码（原题 18）

函数 lproc 的过程体对应的汇编代码如下：

```asm
    movl  8(%ebp), %edx
    movl  12(%ebp), %ecx
    movl  $255, %esi
    movl  $-2147483648, %edi
.L3:
    movl  %edi, %eax
    andl  %edx, %eax
    xorl  %eax, %esi
    movl  %ecx, %ebx
    shrl  %bl, %edi
    testl %edi, %edi
    jne   .L3
    movl  %esi, %eax
```

上述代码根据以下 lproc 函数的 C代码编译生成：

```c

    int val = ______;
    int i;
    for (i = ______; i ______; i = ______) {
        val ^= ______;
    }
    return val;
}
```
