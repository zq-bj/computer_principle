## 3.3.2 传送指令

### 1. 传送指令的类型

- 通用数据传送

- 标志传送
- I/O 信息传送

### 2. 通用数据传送指令

| 指令 | 功能 | 格式（AT&T；src 为源操作数，dst 为目的操作数；b/w/l 表示 8/16/32 位） | 示例及结果 |
|------|------|------|------|
| `mov` | 一般数据传送 | `mov(操作数大小) src, dst`，如 `movl src, dst`（32 位传送） | `movl $5, %eax`：执行后 EAX 为 5 |
| `movs`（符号扩展） | 高位补符号位 | `movs(src操作数大小)(dst操作数大小) src, dst`，如 `movsbl src, dst`（8 位扩展至 32 位） | `movsbl %al, %edx`：若 AL 为 `0x80`，执行后 EDX 为 `0xFFFFFF80`，按有符号整数解释仍为 -128 |
| `movz`（零扩展） | 高位补 0 | `movz(src操作数大小)(dst操作数大小) src, dst`，如 `movzbl src, dst`（8 位扩展至 32 位） | `movzbl %al, %edx`：若 AL 为 `0x80`，执行后 EDX 为 `0x00000080`，即 128 |
| `xchg` | 交换两个操作数 | `xchg(操作数大小) src, dst`，如 `xchgl src, dst`（32 位交换） | `xchgl %eax, %ebx`：若 EAX 原为 5、EBX 原为 8，执行后 EAX 为 8、EBX 为 5 |
| `push` | 将源操作数压栈 | `push(操作数大小) src`，如 `pushl src`（32 位压栈） | `pushl %eax`：若 EAX 为 5、ESP 原为 `0x1000`，执行后 ESP 为 `0x0FFC`，该地址处的 32 位数据为 5 |
| `pop` | 将栈顶数据弹出至目的操作数 | `pop(操作数大小) dst`，如 `popl dst`（32 位出栈） | `popl %eax`：若 ESP 原为 `0x0FFC`、栈顶的 32 位数据为 5，执行后 EAX 为 5，ESP 为 `0x1000` |

#### （1）mov、movs、movz 的区别

三者的区别在于：**是否扩展位数，以及扩展时高位补什么。**

| 指令 | 功能 | 高位处理 |
|------|------|------|
| `mov` | 普通传送，源、目的操作数位数相同 | 不扩展，原样复制 |
| `movs` | 符号扩展传送，小位数扩展到大位数 | 补源数据的符号位：最高位为 1 就补 1，为 0 就补 0 |
| `movz` | 零扩展传送，小位数扩展到大位数 | 全部补 0 |

假设 AL 中存的是 `0x80`，二进制为 `1000 0000`，下面各条指令独立执行：

| 指令 | 执行结果 | 数值含义 |
|------|------|------|
| `movb %al, %bl` | BL = `0x80` | 原样复制 8 位；按有符号数解释为 -128，按无符号数解释为 128 |
| `movsbl %al, %eax` | EAX = `0xFFFFFF80` | 按有符号数解释，仍为 -128 |
| `movzbl %al, %eax` | EAX = `0x00000080` | 按无符号数解释，仍为 128 |

<span style="color:#c0392b; text-decoration:underline">**mov 原样搬，movs 补符号，movz 补零。**</span>

这里的 `movs`、`movz` 表示扩展传送指令的名称前缀，实际书写时需带大小后缀，如 `movsbl`、`movzbl`。

### 2. 算术运算指令

| 指令 | 功能 | 格式（AT&T，以 32 位为例） | 示例及结果 |
|------|------|------|------|
| `add` | 加法：目的操作数 ← 目的操作数 + 源操作数 | `addl src, dst` | `addl $3, %eax`：若 EAX 原为 5，执行后为 8 |
| `sub` | 减法：目的操作数 ← 目的操作数 − 源操作数 | `subl src, dst` | `subl $3, %eax`：若 EAX 原为 5，执行后为 2 |
| `inc` | 加 1：目的操作数 ← 目的操作数 + 1 | `incl dst` | `incl %eax`：若 EAX 原为 5，执行后为 6 |
| `dec` | 减 1：目的操作数 ← 目的操作数 − 1 | `decl dst` | `decl %eax`：若 EAX 原为 5，执行后为 4 |
| `neg` | 算术取负：目的操作数 ← 0 − 目的操作数 | `negl dst` | `negl %eax`：若 EAX 原为 5，执行后按有符号整数解释为 -5 |
| `mul` | 无符号乘法：EAX × src，完整 64 位乘积存入 EDX:EAX（EDX 为高位，EAX 为低位） | `mull src`；src 为寄存器或内存，不能是立即数 | `mull %ebx`：若 EAX 为 6、EBX 为 7，执行后 EAX = 42，EDX = 0 |
| `imul`（单操作数） | 有符号乘法：EAX × src，完整 64 位乘积存入 EDX:EAX | `imull src`；src 为寄存器或内存，不能是立即数 | `imull %ebx`：若 EAX 为 -6、EBX 为 7，执行后 EAX = `0xFFFFFFD6`，EDX = `0xFFFFFFFF`，合起来表示 -42 |
| `imul`（双操作数） | 有符号乘法：dst ← dst × src，只保留低 32 位，不向 EDX 写入高位 | `imull src, dst`；dst 为寄存器，src 可为寄存器或内存；立即数源也有简写形式 | `imull %ebx, %eax`：若 EAX 为 -6、EBX 为 7，执行后 EAX 按有符号整数解释为 -42，EBX 不变 |
| `imul`（三操作数） | 有符号乘法：dst ← src × 立即数，只保留低 32 位 | `imull $立即数, src, dst`；src 为寄存器或内存，dst 为寄存器 | `imull $3, %ebx, %eax`：若 EBX 为 7，执行后 EAX = 21，EBX 不变 |
| `div` | 无符号除法：EDX:EAX ÷ src，商存入 EAX，余数存入 EDX | `divl src`；src 为寄存器或内存，不能是立即数；32 位无符号被除数放入 EAX 后，先将 EDX 清零 | 先令 EAX = 20、EDX = 0、EBX = 6，再执行 `divl %ebx`：EAX = 3，EDX = 2 |
| `idiv` | 有符号除法：EDX:EAX ÷ src，商存入 EAX，余数存入 EDX；商向 0 截断，非零余数与被除数同号 | `idivl src`；src 为寄存器或内存，不能是立即数；32 位有符号被除数放入 EAX 后，先用 `cltd` 符号扩展到 EDX:EAX | 先令 EAX = -20、EBX = 6，执行 `cltd`，再执行 `idivl %ebx`：EAX = -3，EDX = -2 |
