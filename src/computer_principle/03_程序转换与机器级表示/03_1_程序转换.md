## 3.1.2 机器指令与汇编指令的表示

### 1. 机器指令的格式

- 操作码
- 寻址方式
- 寄存器编号
- 立即数（位移量，1B/2B/4B）

| 100010 D W | mod | reg | r/m | disp8 |
|------------|-----|-----|-----|-------|
| 100010 0 0 | 01 | 001 | 001 | 11111010 |

### 2. 汇编指令的表示

#### （1）Intel 格式

```asm
mov [bx+di-6], cl
```

#### （2）AT&T 格式（本课程使用）

```asm
movb %cl, -6(%bx,%di)
```

#### （3）寄存器传送语言 RTL

```text
M[R[bx]+R[di]-6] ← R[cl]
```

### 3. AT&T 格式相对于 Intel 格式的区别

- 指令名后的字母表示操作数的大小。
- 寄存器名前使用 `%` 前缀，立即数前使用 `$` 前缀。
- 内存引用使用括号而不是方括号。
- 在有偏移的内存引用中，基址、索引、比例和偏移量的顺序与 Intel 格式不同。
- <span style="color:#c0392b; text-decoration:underline">**AT&T 格式源操作数在目标操作数之前。**</span>

## 3.1.3 指令集体系结构 ISA 规定的内容

### 1. ISA 规定的内容

- 指令格式、操作类型。
- 操作数的类型。
- 寄存器的名称、编号、长度、用途等。
- 操作数能存放的存储空间大小和编址方式。
- 大端序还是小端序。
- 寻址方式。

## 3.1.4 高级语言转换成机器语言

### 1. 转换过程

```mermaid
flowchart LR
    A[高级语言源程序] -->|预处理| B[hello.i<br/>源码]
    B -->|编译| C[hello.s<br/>汇编语言源码]
    C -->|汇编| D[可重定位目标文件<br/>二进制]
    D -->|链接| E[可执行目标文件<br/>二进制]
```

### 2. gcc 生成机器代码

| 步骤 | 命令 |
|------|------|
| 一步到位 | `gcc -O1 hello1.c hello2.c -o hello` |
| 预处理 | `gcc -E hello1.c -o hello1.i` |
| 编译 | `gcc -S hello1.i -o hello1.s` |
| 汇编 | `gcc -c hello1.s -o hello1.o` |
| 链接 | `gcc hello1.o hello2.o -o hello` |

## 3.1.5 汇编指令的操作数与格式

### 1. 寄存器内容

`%` + 名字，如 `%ebp`。

RTL：

```text
R[ebp]
```

### 2. 存储器内容

格式：`偏移量(基址寄存器, 变址寄存器, 比例因子)`。

<span style="color:#c0392b; text-decoration:underline">**计算：基址寄存器 + 变址寄存器 × 比例因子 + 偏移量。**</span>

例如：

```asm
100(%ebx, %esi, 4)
```

存储单元的地址为：寄存器 ebx 的内容加上（寄存器 esi 内容乘以 4），再加 100。

RTL：

```text
M[R[ebx] + 4 × R[esi] + 100]
```

### 3. 汇编指令格式

格式：`op src, dst`，表示：`dst ← dst op src`。

例如：

```asm
addl (, %ebx, 2), %eax
```

RTL：

```text
R[eax] ← R[eax] + M[2 × R[ebx]]
```

## 3.1.6 gcc 生成的汇编代码与反汇编代码

### 1. C语言代码

```c
// test.c
#include <stdio.h>
int add(int i, int j)
{
    int x = i + j;
    return x;
}
```

### 2. gcc 生成的汇编代码

```asm
add:
    pushl %ebp
    movl  %esp, %ebp
    subl  $16, %esp
    movl  12(%ebp), %eax
    movl  8(%ebp), %edx
    leal  (%edx,%eax), %eax
    movl  %eax, -4(%ebp)
    movl  -4(%ebp), %eax
    leave
    ret
```

### 3. 反汇编得到的汇编代码（objdump）

`00000000 <add>:`

| 位移量 | 机器指令 | 汇编指令 |
|--------|----------|----------|
| 0 | `55` | `push %ebp` |
| 1 | `89 e5` | `mov %esp,%ebp` |
| 3 | `83 ec 10` | `sub $0x10,%esp` |
| 6 | `8b 45 0c` | `mov 0xc(%ebp),%eax` |
| 9 | `8b 55 08` | `mov 0x8(%ebp),%edx` |
| c | `8d 04 02` | `lea (%edx,%eax,1),%eax` |
| f | `89 45 fc` | `mov %eax,-0x4(%ebp)` |
| 12 | `8b 45 fc` | `mov -0x4(%ebp),%eax` |
| 15 | `c9` | `leave` |
| 16 | `c3` | `ret` |
