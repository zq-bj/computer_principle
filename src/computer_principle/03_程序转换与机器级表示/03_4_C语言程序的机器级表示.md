## 3.4.2 过程调用

### 1. 过程调用（P 调用 Q）

1. P 将实参放到 Q 能取到的地方。
2. P 将返回地址压栈，然后把控制转移到 Q。
3. Q 保存 P 的现场，给自己的内部非静态局部变量分配空间。
4. 执行 Q 的函数体。
5. Q 恢复 P 的现场，释放局部变量所占空间。
6. Q 取出返回地址，把控制转移到 P。

## 3.4.3 按值传参、按地址传参

### 1. 传参方式

- 按值传参：基本数据类型（整形、浮点型、字符型）。
- 按地址传参：数组、结构体、指针。

### 2. 程序示例

#### 1）程序一

```c
#include <stdio.h>
main() {
    int a = 15, b = 22;
    printf("a=%d\tb=%d\n", a, b);
    swap(&a, &b);
    printf("a=%d\tb=%d\n", a, b);
}
swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}
```

#### 2）程序二

```c
#include <stdio.h>
main() {
    int a = 15, b = 22;
    printf("a=%d\tb=%d\n", a, b);
    swap(a, b);
    printf("a=%d\tb=%d\n", a, b);
}
swap(int x, int y) {
    int t = x;
    x = y;
    y = t;
}
```

### 3. 传递 swap 过程参数的汇编代码片段

#### （1）程序一汇编代码片段

```asm
main:
    # ...
    leal -8(%ebp), %eax
    movl %eax, 4(%esp)
    leal -4(%ebp), %eax
    movl %eax, (%esp)
    call swap
    # ...
    ret
```


## 3.4.4 选择语句

选择语句先比较条件、设置标志位，再通过条件跳转选择执行分支；各分支完成后汇合到后续代码。

## 3.4.5 循环语句

### 1. for 语句及对应形式

```c
for (begin_expr; cond_expr; update_expr)
    loop_body_statement
```

对应形式：

```c
begin_expr;
c = cond_expr;
if (!c) goto done;
loop: loop_body_statement
update_expr;
c = cond_expr;
if (c) goto loop;
done:
```
